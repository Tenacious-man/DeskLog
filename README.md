# 桌面任务记录板

一个只在本机保存记录的 Windows 桌面小工具：记任务、点完成、月底查看工作记录。

## 运行

解压整个 `DeskLog-win-x64.zip` 文件夹，双击其中的 **DeskLog.exe**。请保留文件夹内的其他文件。无需安装 .NET、登录账号或联网。

任务板默认位于主屏幕右侧。拖动顶部日期区域可以移动位置；顶部 `···` 菜单可以恢复到右侧。面板下方的「本月记录」打开历史记录窗口。

1.0.5 默认启用「固定到桌面」，采用米白与淡绿色界面。所有窗口不占任务栏，只保留托盘。顶部菜单可切换固定模式；隐藏到托盘后不会自行出现。启动参数 `--window` 可在启动时使用普通窗口模式。

程序运行时通知区域会出现一个图标（可能位于任务栏的隐藏图标菜单中）。右键可显示任务板、添加任务、打开月度记录、设置开机启动或退出。开机启动默认关闭；启用后不要移动程序文件夹，移动后请重新设置。

## 透明度

右上角「··· → 透明度…」或托盘菜单中打开设置。0% 完全不透明，80% 最透明；包括文字在内的整个面板都会变化。拖动实时预览，点击保存后重启保留；直接关闭设置窗口撤销本次调整。

## 日常使用

- **添加任务**：只需填写名称，截止日期和备注可以留空。
- **编辑任务**：点击任务名称；勾选「这件事已完成」可以直接补记完成的工作，并修正完成日期。
- **完成 / 恢复**：点击任务左侧的圆圈标记完成，点击已完成任务左侧的勾恢复为待办。
- **截止状态**：逾期和今天截止用不同文字、颜色显示，不弹通知。
- **查看月份**：进入本月记录，使用左右箭头或年月选择框查看历史；有备注的记录可展开。
- **删除任务**：编辑窗口内选择删除并确认。删除项不再显示，但底层记录保留。
- **退出**：从托盘或任务板菜单选择退出。有未关闭的编辑窗口时会提示。

完成记录按实际记录的本地完成日期归档。恢复为待办会清除该任务当前的完成日期；再次完成后按新日期归档。程序不保留同一任务反复完成的多个版本。

## 本地数据与备份

记录保存在 `%LOCALAPPDATA%\DeskLog\desklog.db`，位置设置也在此数据库中。程序更新或移动不会清空记录。

每天首次运行，以及跨天持续运行时，会在同目录的 `backups` 文件夹备份数据库，保留最近 7 份。备份是生成时的快照，无法恢复快照之后的新修改。

恢复方法：

1. 从托盘退出程序。
2. 打开 `%LOCALAPPDATA%\DeskLog`，先将当前 `desklog.db` 复制到别处保存。
3. 从 `backups` 中选择日期合适的 `.db` 文件，复制到上一级并改名为 `desklog.db`，替换当前文件。
4. 重新启动程序，检查任务和月份记录。

诊断日志位于同目录 `app.log`。日志记录程序状态及错误，不主动记录任务名称或备注。

## 桌面行为与兼容性

桌面模式使用独立绘制的窗口并维护桌面层级，避免将 WPF 窗口嵌入 Explorer 引起黑屏。使用桌面窗口的所有权关系保持层级，不再定时恢复窗口或临时置顶；固定模式拒绝最小化指令，显式隐藏到托盘仍正常；不修改壁纸和图标。1.0.5 已由用户确认：连续按两次 Win+D，任务板持续显示，没有闪烁。

第一版面向 Windows 11 x64，不承诺其他壁纸工具共存。实际已验证项及尚需人工验收项见 `VALIDATION.md`。

## 从源码构建

需要 .NET 10 SDK。仓库中运行：

```powershell
.\scripts\build.ps1
```

SDK 不在路径中时：

```powershell
.\scripts\build.ps1 -Dotnet "$env:USERPROFILE\.dotnet\dotnet.exe"
```

脚本先运行数据测试，再生成包含运行时的 Windows x64 发布文件夹及 ZIP 包，输出在 `artifacts`。

测试使用独立临时目录，不接触个人记录。开发时可运行 `DeskLog.exe --preview --data-dir "独立的绝对目录"`，检查界面；加上 `--window` 可使用普通窗口。预览模式禁用开机启动设置。

工程分为 `DeskLog.Core`（记录规则与 SQLite）、`DeskLog.App`（WPF 界面、桌面集成、托盘）和 `DeskLog.Tests`（自动化数据测试）。没有网络接口或云端服务。
